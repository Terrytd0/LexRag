# Architecture Decision Records

`docs/architecture.md` captures the foundational, system-wide decisions made
on Day 1. Later, narrower decisions that deserve their own record (e.g.
"why we switched rerank top-k from 20 to 50", "why we added a Pinecone
adapter") go here as `NNN-title.md`, one file per decision, using the
standard Context / Decision / Consequences format.
